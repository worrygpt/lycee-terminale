# Fonctions trigonométriques (Spé Maths)

## Rôle de Claude
Réactiver d'abord le cercle trigonométrique (tout en découle), faire dessiner l'élève, puis dérouler les méthodes d'équations et d'études de fonctions.

## Le socle : cercle trigo et valeurs remarquables
x : 0, π/6, π/4, π/3, π/2 → cos x : 1, √3/2, √2/2, 1/2, 0 → sin x : 0, 1/2, √2/2, √3/2, 1.
Relations : cos²x + sin²x = 1 · cos(−x) = cos x (paire) · sin(−x) = −sin x (impaire) · cos(x+2π) = cos x, sin(x+2π) = sin x (période 2π) · cos(π−x) = −cos x · sin(π−x) = sin x · cos(π/2 − x) = sin x.

## Équations trigonométriques (méthode systématique)
- **cos x = cos a** ⟺ x = a + 2kπ ou x = −a + 2kπ (k ∈ ℤ).
- **sin x = sin a** ⟺ x = a + 2kπ ou x = π − a + 2kπ (k ∈ ℤ).
- cos x = valeur : reconnaître la valeur remarquable, écrire cos x = cos a, résoudre. Sur un intervalle donné (ex. ]−π ; π]) : lister les solutions en testant les k.
- Inéquations : lecture sur le cercle trigonométrique (colorier l'arc solution).

## Dérivées et études de fonctions
(cos x)' = −sin x · (sin x)' = cos x · (cos(ax+b))' = −a·sin(ax+b) · (sin(ax+b))' = a·cos(ax+b).
Étude type de f(x) = cos/sin composés :
1. Réduire l'intervalle d'étude par **périodicité** puis **parité** (le justifier proprement).
2. Dériver, résoudre f'(x) = 0 ou étudier son signe sur l'intervalle réduit (souvent via le cercle).
3. Tableau de variations, puis compléter la courbe par symétries/translations.
Limites : cos et sin n'ont PAS de limite en ±∞ ; mais −1 ≤ cos x ≤ 1 permet gendarmes et comparaisons (ex. sin(x)/x → 0 en +∞).

## Pièges fréquents
Oublier le « + 2kπ » ou la deuxième famille de solutions · confondre les deux familles de cos et de sin · dériver cos en +sin · travailler en degrés (tout est en radians) · oublier de restreindre les solutions à l'intervalle demandé.

## Entraînement
Dictée de valeurs remarquables · série d'équations cos/sin sur intervalle · une étude complète avec réduction du domaine.
